# Annotation Task — Instructions

Thank you for helping with this coding task.

You will assign a code to each of 113 short research claims about
Continuous Integration (CI). The task should take roughly 60–90 minutes.

---

## Your files

| File | What it is |
|---|---|
| `annotation_sheet_<yourname>.csv` | The 113 claims. This is the file you fill in and return. |
| `CODEBOOK_reference.csv` | The 31 available codes and their definitions. Reference only — do not edit. |

Keep both open side by side while you work.

---

## What to do

For each row in your annotation sheet:

1. Read the text in **`Claim Text`**.
2. Choose the **single best-fitting code** from the 31 codes in
   `CODEBOOK_reference.csv`.
3. Copy that code into the **`Your Code`** column.
4. Optionally, add a brief remark in **`Notes (optional)`** — for
   example if you hesitated between two codes, or found the claim
   unclear.

---

## Rules

1. **Exactly one code per claim.** Do not leave any row blank and do
   not assign two codes.

2. **Copy and paste the code text.** Do not retype it from memory and
   do not abbreviate it. The code in your sheet must match the
   codebook exactly, character for character.

3. **Base your decision only on what the claim text says.** Do not
   infer context, intent, or causality that is not stated.

4. **If no code fits well, choose the closest one** and note your
   hesitation in the Notes column.

5. **Work alone.** Please do not discuss the task, the claims, or your
   answers with anyone else — including the other people doing this
   task — until you have submitted your sheet.

6. **Do not use any AI tool** (ChatGPT, Claude, Gemini, Copilot, or
   similar) at any point, and do not search the web for the original
   papers these claims came from.

7. **Complete the sheet in one pass.** Work through the rows in the
   order given. Once you have answered a row, please do not go back
   and revise it.

8. **Do not reorder or rename the rows or columns.**

---

## Three notes on the codebook

- The 31 codes are listed **alphabetically**, not grouped by topic.
  Please read through the full list once before you begin, so you know
  what is available.

- **Three of the 31 codes have no written definition.** This is a
  property of the original source material, not an oversight in your
  file. If one of those seems to be the best fit, use it and rely on
  the code label itself.

- The claim texts and the code labels are reproduced exactly as they
  appear in the original published dataset, including their
  capitalisation and any wording irregularities. Please do not correct
  them.

---

## Returning your work

Save the file with the **same filename** in CSV format and send it
back. Please do not convert it to another format.

If anything about the *mechanics* of the task is unclear, ask before
you start. Please note that we will not be able to answer questions
about which code is "correct" for a particular claim — that judgement
is precisely what we are asking you to make.

Thank you.
